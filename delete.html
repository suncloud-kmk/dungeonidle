계정과 데이터 삭제

앱: 던전 관리인 키우기

1. 게임 안에서 지우기

게임 > 설정 > 데이터 삭제를 누르고 확인하면 바로 지워집니다.

2. 앱을 지운 뒤 요청하기

구글 플레이의 '던전 관리인 키우기' 소개 화면에 있는 개발자 이메일로 아래 내용을 보내 주세요. 본인 확인 뒤 30일 안에 지우고 알려 드립니다.

  • 제목: 데이터 삭제 요청
  • 게임 이름(채팅·랭킹에 보이는 이름)
  • 구글 계정을 연결했다면 그 구글 이메일

3. 지워지는 것

  • 게임 이름, 이용자 번호, 비밀 키
  • 랭킹 기록과 성장 정보
  • 채팅 글과 신고 기록
  • 구글 계정 연결 정보와 서버에 저장한 진행 사본

4. 남는 것

접속 주소를 알아볼 수 없게 바꾼 값은 부정 이용을 막기 위해 최대 1일 보관한 뒤 지웁니다. 서버의 자동 백업에 남은 것은 백업 보관 기간이 지나면 함께 지워집니다.
